# Manual list tags

Sessions: 7eda2223-acf7-410d-8c3f-2f831e09d391

## Decisions

- **The short text shown on a title in a hand-picked list is called a tag.**
- **The backend sends the tag as an optional `tag` on each poster.** Only titles in a `manual:`
  list of an explore tab have one.
- **The tag rises once, then keeps wiggling while the card is on screen.** It never hides and
  rises again, unlike the looping timeline in Figma.
